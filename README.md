# Пупырка

Маленькая игра, чтобы выдохнуть. Один файл HTML, без сборки и зависимостей.

**Играть:** https://eduardelrikgara-beep.github.io/pupyrka/

## Что это

Мини-игра от студии **Soft Crash Games**. Лопается пузырчатая плёнка — и всё.
Никаких проигрышей, таймеров и давления. Иногда этого достаточно.

## Как запустить локально

Скачать `index.html` и открыть в браузере. Всё.

## Технически

- один файл, ~60 КБ, чистый HTML + CSS + JS;
- звук синтезируется в браузере (Web Audio), файлов нет;
- внешняя зависимость: SDK GameMonetize (`api.gamemonetize.com/sdk.js`) — только для rewarded-рекламы по кнопке. На GitHub Pages он не мешает игре.
